Lập trình là gì?

Tìm số lớn nhất trong trong 100 số nguyên

  1. Số lớn nhất là max
  2. Giả sử max = số thứ nhất
  3. Thử hết các số còn lại xem có số nào lớn hơn số max thì cho max bằng số đó
#include <stdio.h>
int main(){
  int A[] = {2, 6, 8, 5, 90, 32, ..};
  int max = A[0];
  for(int i = 1; i < 100; i++){
      if (A[i] > max)
          max = A[i];
  }
  printf("Max = %d", max);
}

Lập trình là gì?

Là quá trình truyền đạt thông tin giữa con người và máy tính tương tự như cách hai người giao tiếp với nhau.

Là quá trình viết mã lệnh để điều kiển máy tính thực hiện một nhiệm vụ cụ thể.

#include <stdio.h>  // 1️⃣ Thư viện tiêu chuẩn
#define PI 3.14159   // 2️⃣ Định nghĩa hằng số
// 3️⃣ Khai báo hàm
double tinhChuVi(double r);
// 4️⃣ Hàm main (bắt đầu chương trình)
int main() {
   double banKinh = 5.0;
   double chuVi = tinhChuVi(banKinh);
   printf("Chu vi hình tròn có bán kính %.2f là %.2f\n", banKinh, chuVi);
   return 0;  // Kết thúc chương trình
}
// 5️⃣ chương trình con
double tinhChuVi(double r) {
   return 2 * PI * r;
}
